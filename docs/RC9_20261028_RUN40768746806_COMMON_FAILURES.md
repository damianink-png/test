## Independent diagnostic replay on archived Trident revision A/B BReps

Both original BReps are valid. A separate Linux OCP replay with three *diagnostic-only* configurations (standard, OBB disabled, parallel) returned exactly the same negative signed volume **-122.58159431091562 mm³** and invalid topology. Simply reversing the Common orientation also leaves invalid topology. This rules out a basic OBB/parallel configuration workaround; it does not prove that no valid algorithm exists.

New `ci/rc9_common_probe.py` performs bounded independent post-failure diagnostics from the exact captured BRep pair. The workflow writes `evidence/common-probe.json` after a failed CAD scenario. Probe results are **never used as comparison evidence** and do not weaken the 0.01 mm proof budget, SAME/MOVED rules, STEP colors, HTML or BOM assertions.
