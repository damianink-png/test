## Root cause confirmed from archived real B-Rep pairs

The virtual-offset candidate stage **did** find a correct translation for V2 shift: B→A approximately (-1275, +395, -210) mm, with 1705 individually certified pairs and zero original-frame matches. However, not every occurrence is certified, so the final compare still attempts residual native proofs. The residual A[105]/B[105] has 718 faces on both sides, with A topologically invalid and B valid. The exact face-type/orientation histogram differs by **one BSpline face orientation**; A face 617 is nearly zero-area and its nearest geometric B counterpart has opposite orientation. Strict oriented-boundary equality therefore **cannot be asserted** from the existing proof, even though dimensions and locations are close. Do not mark this pair SAME based on centroid, volume, face count, or a sample.

The Trident shifted residual A[245] is also invalid while B is valid. On archived shapes, copy-only repair rejects both \`_shape_fix\` and \`_wire_fix\` because they increase stored vertex tolerance (initial maximum ~0.009827 mm). The worker then previously stalled while unwinding native OCCT objects, exhausting 90 seconds. This is a teardown/diagnostics problem **in addition to** the unproven geometry.

## Targeted patch and local real-shape verification

\`ci/patch_rc9_repair_failfast.py\` now writes \`ok:false\` with the exact \`UnprovenRepair\` reason and exits the disposable child with code 70 before native teardown. The coordinator treats this as **INCOMPLETE**, never SAME/CHANGED. Regression: \`ci/test_rc9_repair_failfast.py\`.

These local times are **not** a Windows performance guarantee.
