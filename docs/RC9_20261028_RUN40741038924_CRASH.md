## Diagnostic improvement in this branch

The previously configured _preserve_failure() only saves the FIRST failed native pair, so it cannot preserve the pair causing a later uncatchable access violation. New ci/patch_rc9_active_world_capture.py captures the two most recently serialized B-Rep pairs *before* the child proof is invoked. It stores exact A/B bytes and current.json under FAILED_BREP/active_world. Enabled only by DSCOMPARE_CAPTURE_ACTIVE_BREP=1 (CAD CI); no matching behavior or tolerance is changed. Windows user-scoped WER minidumps and faulthandler logs are also collected into evidence on failures.

Regression verified locally using a three-request ring with byte-for-byte assertions and a real Voron V2 archived pair: guarded_world_reexport returned True at 0.01 mm while the capture retained exact original B-Rep bytes. This does not fix the crash; it makes its precise native inputs available for the next investigation.
